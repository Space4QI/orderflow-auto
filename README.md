# OrderFlow Auto

Backend application for automotive service management.

## Requirements

- Go 1.26.3 or compatible version

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Space4QI/orderflow-auto.git
cd orderflow-auto
```

Run the application:

```bash
go run ./cmd/api
```

Build the application:

```bash
go build -o orderflow-auto ./cmd/api
```

## Project Structure

- `cmd/api` — application entry point.
